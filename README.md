# 했냐옹 🐱

중요한 일정을 잊어버린 경험, 한 번쯤 있으신가요?

했냐옹은 일정과 할 일을 프로젝트별로 관리하고, 한눈에 확인할 수 있도록 도와주는 개인 일정 관리 서비스입니다. 캘린더에서 한 달 전체 일정을 살펴보고, 대시보드에서 오늘과 내일의 주요 일정 및 할 일을 빠르게 확인할 수 있습니다.

Nuxt 4 · Vue 3 · Nitro · TypeScript · Neon PostgreSQL

배포 전 설정과 외부 서비스 결정 사항은 [운영 준비 체크리스트](docs/production-readiness.md)를 참고해주세요.

## 로컬 실행

`.env`에 Neon 연결 정보를 설정한 뒤 실행합니다.

```bash
npm install
npm run dev
```

`http://localhost:3000/login`에서 회원가입하거나 로그인하면 프로젝트·태스크·일정·캘린더·리마인더를 사용할 수 있습니다. 알림 설정은 실제 Slack 예약 API에 연결됩니다.

프론트 구조와 API 연결, 검증 범위는 [프론트엔드 문서](docs/frontend.md)를 참고해주세요. 기존 배포된 정적 미리보기와 Nuxt 앱은 별개입니다.
