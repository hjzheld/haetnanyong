# 했냐옹 🐱

중요한 일정을 잊어버리거나, 해야 할 일을 놓친 경험이 있으신가요?

**했냐옹**은 프로젝트별 일정과 할 일, 개인 플랜을 한곳에서 관리하는 서비스예요. 홈과 캘린더에서 계획을 확인하고, Slack으로 일정 알림도 받을 수 있어요.

- **서비스:** [haetnanyong.vercel.app](https://haetnanyong.vercel.app/)
- **기술:** Nuxt 4 · Vue 3 · TypeScript · Nitro · Neon PostgreSQL · Slack API

## 어떤 문제를 해결하나요?

약속·학습·업무·사이드 프로젝트를 함께 관리하다 보면 계획이 흩어지고 기한을 놓치기 쉬워요. 일정과 할 일을 한곳에 모으고, 다가오는 마감과 놓친 작업을 확인할 수 있게 만들었어요.

## 누가 사용하나요?

여러 프로젝트와 개인 계획을 함께 정리하거나, 평소 사용하는 Slack으로 일정 알림을 받고 싶은 분을 생각하며 만들었어요.

## 핵심 기능은 무엇인가요?

- **계획 관리:** 프로젝트별로 또는 개별 항목으로 일정과 할 일을 등록해요.
- **계획 확인:** 홈에서 오늘 일정·3일 이내 마감·지연된 미완료 할 일을, 캘린더에서 한 달 일정을 확인해요.
- **Slack 알림:** 연결한 본인 Slack 계정으로 예약한 시각에 일정 알림을 받아요.

## 이렇게 사용해요

[배포 사이트](https://haetnanyong.vercel.app/)에서 직접 가입해 사용해보세요. 닉네임은 비워두면 자동으로 만들어지고, Slack을 연결하지 않아도 계획 관리는 사용할 수 있어요.

**먼저 일정을 등록해요.**

1. **플랜 → 플랜 등록**에서 일정을 선택하고 프로젝트를 고르거나 새로 만들어주세요.
2. 제목과 시작·종료 시각을 입력하고 저장해주세요.
3. 프로젝트 상세와 캘린더에 일정이 보이는지 확인해주세요.

**Slack 알림도 받아보세요.**

1. **마이페이지 → Slack 연결**에서 본인 계정을 승인하고 **테스트 DM 보내기**로 수신을 확인해주세요.
2. 일정 상세에서 알림 시각을 설정해주세요. **직접 지정**으로 몇 분 뒤를 선택하면 확인하기 편해요.
3. 예약한 시각에 실제 Slack DM이 도착하는지 확인해주세요.

알림은 현재부터 1분 이후, 120일 이내로 예약할 수 있어요. 시간은 KST 기준이고, 종일 일정의 종료일은 포함하지 않아요. Slack 연결은 워크스페이스 정책에 따라 관리자 승인이 필요할 수 있어요. 자세한 설정은 [Slack 연결 안내](docs/slack-oauth.md), 가입·로그인 횟수 제한은 [운영 안내](docs/vercel-operations.md)를 참고해주세요.

## 이번 과제에서 구현한 범위

| 영역          | 구현 내용                                                                                     |
| ------------- | --------------------------------------------------------------------------------------------- |
| 플랜·프로젝트 | 프로젝트 소속·개별 일정과 할 일 등록·조회·수정·삭제, 할 일 완료, 프로젝트 보관·복원·보관 제안 |
| 홈·캘린더     | 오늘 일정·다가오는 마감·지연된 할 일, 월간 일정과 종료된 일정 구분                            |
| 계정          | 가입·로그인·로그아웃, 닉네임·비밀번호 변경, 다른 기기 로그아웃, 탈퇴                          |
| Slack         | OAuth 연결·해제, 테스트 DM, 알림 예약·취소·불확실한 예약 결과 재확인                          |
| 공통 UI       | 모바일 대응, 밝은·어두운 테마, 한국어·영어, 모달·도움말·오류 안내                             |

이번에는 **개인의 계획 등록·확인·알림 수신**에 집중했어요. 로그인과 DB는 사용자별 데이터 저장을 위해 연결했고, 팀원 초대·공유 권한 같은 협업 기능은 다음 범위로 남겨뒀어요.

## 만들면서 이렇게 정했어요

- **일정과 할 일 구분:** 시간에 맞춰 확인할 일정과 완료를 체크할 할 일을 나눴어요. 캘린더와 Slack 알림은 일정에 연결했어요.
- **프로젝트는 선택:** 간단한 약속이나 할 일은 프로젝트 없이도 등록할 수 있게 했어요.
- **실패해도 다시 이어서:** 저장 실패 시 입력을 유지하고, 새 프로젝트를 만든 뒤 항목 저장에 실패해도 재시도에서 프로젝트가 중복 생성되지 않도록 했어요.
- **불확실한 알림은 바로 재예약하지 않기:** 중복 예약을 막기 위해 상태를 남겨두고 Slack 예약 목록과 다시 비교해요. 예약 접수나 시간 경과를 실제 수신 성공으로 판단하지는 않아요.

## AI는 어디에 활용했나요?

웹 ChatGPT는 기획·화면과 데이터 구조 검토·이미지 제작에, IDE의 AI 코딩 도구는 화면·API·SQL 구현과 오류 분석·자동 검사에 활용했어요. 필요한 기능과 화면 방향, 우선순위는 제가 정했고, 외부 계정 설정·환경변수 입력·배포·실제 사용 확인도 직접 진행했어요. 코드와 검사 코드 모두 AI의 도움을 받았어요.

### 사례 1. 특정 PC에서 언어·테마가 바뀌지 않는 문제

다른 기기에서는 정상인데 특정 PC에서는 항목을 누르면 메뉴가 닫히기만 했어요. 같은 PC에서도 자동 조작은 성공해, 이 차이와 발생 환경·코드를 AI에 전달하며 원인을 좁혔어요. 포커스 목적지가 `null`일 때 메뉴를 바로 닫던 처리를 보완한 뒤, 자동 검사와 문제 PC의 실제 마우스 선택으로 정상 동작을 확인했어요. 수정 전 이벤트 순서는 기록하지 않아 원인 추정과 해결 결과는 구분했어요.

### 사례 2. Slack DM이 도착하지 않는 문제

API 응답의 `messages_tab_disabled` 메시지를 근거로 Slack 공식 문서를 참고해 앱의 Messages Tab 설정을 수정했어요. 이후 테스트 DM과 실제 예약 메시지를 각각 받아봤어요. 화면의 연결 표시만으로 끝내지 않고 실제 수신까지 확인하는 기준을 세웠어요.

### 사례 3. 프로젝트 보관 조건 보완

AI 도구의 코드 점검에서 보관 제안이 화면의 완료 판단에만 의존하는 부분을 찾았어요. 서버에서도 조건을 확인하도록 보완하고, 모의 API 브라우저 검사로 실패 안내·재시도·복원 후 동작을 확인했어요. 실제 DB의 동시 요청까지 검증한 결과와는 구분했어요.

기능별 활용 범위와 상세 과정은 [AI 활용 상세](docs/ai-usage.md)에 정리했어요.

## 직접 확인한 기능과 자동 검사

**2026-10-22 기준**, 직접 사용한 결과와 AI 도구의 자동 검사 결과를 나눠 기록했어요.

- **직접 확인:** 배포 사이트 이용, Slack 연결과 실제 메시지 수신, 여러 기기의 언어·테마 선택을 확인했어요. 문제 PC도 수정 후 실제 마우스 선택에 성공했어요.
- **자동 검사:** 모의 API로 등록·수정·보관·복원·오류 처리·반응형을 검사했고, 날짜·인증·알림 로직의 회귀 검사와 타입 검사·프로덕션 빌드를 통과했어요. 빌드한 서버에서도 브라우저 검사를 진행했어요.

이후 수정 사항과 검사별 조건·한계는 [검증 기록](docs/validation.md)에 정리했어요.

## 아직 남은 기능과 확인하지 못한 부분

- **추가 확인:** 대량 데이터 성능, 여러 요청이 겹칠 때의 동작, 실제 Slack 장애와 탈퇴 후 취소 재시도는 운영 환경에서 더 확인해야 해요. 취소 재시도 내역은 화면에서 볼 수 없어 서버 기록·DB·Slack 확인이 필요해요.
- **미지원 기능:** 비밀번호를 잊었을 때 이메일로 재설정하는 기능, 이메일 인증·주소 변경은 아직 없어요. 로그인 후 비밀번호 변경은 가능해요. Slack Org 전체 설치와 Token Rotation도 지원하지 않아요.

### 다음에는 이런 기능을 추가하고 싶어요

- Slack 게시 기록으로 알림 발송 여부를 확인하고 싶어요.
- 캘린더 날짜별 일정 목록·상세 모달, 공휴일·주말 표시와 모바일 가독성을 개선하고 싶어요.
- 도움말에 GIF나 짧은 영상을 넣어 사용 방법을 쉽게 보여주고 싶어요.
- 프로젝트에 팀원을 초대하고 역할·유닛별로 일을 나눌 수 있게 하고 싶어요. 팀장은 전체 일정과 팀원의 Slack 연결 상태를 확인할 수 있게 하려고 해요.
