# 했냐옹 🐱

프로젝트별 일정과 할 일, 개인 플랜을 한곳에서 관리하는 서비스예요. 홈과 캘린더에서 계획을 확인하고, Slack으로 일정 알림을 받을 수 있어요.

**사이트:** [haetnanyong.vercel.app](https://haetnanyong.vercel.app/)

## 주요 기능

- **프로젝트와 개인 플랜:** 프로젝트별로 또는 개별 항목으로 일정과 할 일을 등록하고 관리해요.
- **홈:** 오늘 일정, 다가오는 마감, 기한이 지난 미완료 할 일을 확인해요.
- **캘린더:** 월간 일정을 확인하고, 날짜나 일정을 누르면 상세 모달을 볼 수 있어요. 모바일에서는 일정 색상의 발자국이나 막대로 표시해요.
- **Slack 알림:** 본인 Slack 계정을 연결하고 원하는 시각에 일정 알림을 받아요.
- **화면 설정:** 밝은·어두운 테마와 한국어·영어를 지원해요.

## 사용 방법

1. [사이트](https://haetnanyong.vercel.app/)에서 가입하고 로그인해주세요.
2. **플랜**에서 일정이나 할 일을 등록해주세요. 프로젝트 없이 개인 플랜으로도 사용할 수 있어요.
3. 홈과 캘린더에서 계획을 확인해주세요.
4. 알림이 필요하면 **마이페이지 → Slack 연결**에서 계정을 연결하고, 일정 상세에서 알림 시각을 설정해주세요.

Slack을 연결하지 않아도 계획 관리는 사용할 수 있어요. 시간은 한국 표준시(KST) 기준이고, 종일 일정의 종료일은 포함하지 않아요.

## 기술

Nuxt 4 · Vue 3 · TypeScript · Nitro · Neon PostgreSQL · Slack API
