# 화면과 CSS 규칙

- 상세 카드와 목록에 얇은 색상 띠, 모서리에만 남는 색 조각(‘손톱때’ 장식)을 만들지 않습니다. 기존 왼쪽 색상 테두리도 제거했습니다. 프로젝트 색상은 명확한 색상 샘플과 캘린더 일정 전체 배경으로 표현합니다.
- 할 일의 우선순위는 공통 `PriorityBadge`로 표시합니다. 높음은 로즈, 보통은 앰버, 낮음은 세이지이며 밝은/어두운 테마 모두 배경과 글자색을 함께 지정합니다. 색상만으로 의미를 전달하지 않습니다.
- 선택 입력은 공통 `Select`를 사용합니다. 기본 OS 선택창에 CSS를 덧씌우지 않고 목록의 간격·모서리·hover·선택 상태·키보드 초점을 함께 관리합니다. 팝오버는 모달 안에서도 잘리지 않게 표시합니다.
- 마이페이지 카드 안의 동작 버튼은 PC에서 내용에 맞는 너비로 가로 배치하고, 모바일(600px 이하)에서만 전체 너비로 표시합니다. 높이는 48px이며 버튼 사이 간격은 컨테이너의 gap으로 관리합니다.
- 캘린더에는 일정만 표시합니다. 할 일은 별도 목록과 대시보드에서 확인합니다. 지연된 할 일은 KST 기준 마감일이 지난 미완료 작업이며 다가오는 마감과 분리합니다.
- 사용자에게는 ‘태스크’ 대신 ‘할 일’로 표기합니다. API 경로와 DB의 `tasks` 이름은 유지합니다.
- 공통 컨트롤은 `assets/css/controls.css`에서 관리합니다. 같은 컴포넌트에 새 페이지별 스타일을 중복해서 추가하지 않습니다.

상단 메뉴는 플랜으로 통합합니다. 플랜 페이지에서 프로젝트/개별 탭을 제공하며 프로젝트는 진행 중/보관함으로 구분합니다. 도움말 모달은 플랜 페이지에 제공합니다. 플랜 등록은 할 일 입력 폼으로 바로 열립니다. 프로젝트 드롭다운에 프로젝트 없이 진행/진행 중 프로젝트 목록/새 프로젝트 등록하기를 표시하며, 새 프로젝트 선택 시 이름과 색상을 같은 폼에서 입력합니다. 프로젝트 생성 후 항목 저장에 실패하면 생성된 프로젝트를 유지해 재시도 시 중복 생성하지 않습니다.
