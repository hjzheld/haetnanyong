# 검증 기록

기록 기준일: **2026-10-22 (KST)**. 이 문서는 사용자 직접 확인, AI 도구의 자동 검사, 아직 확인하지 않은 범위를 모아 정리합니다. 각 결과는 해당 실행 조건에 대한 기록이며 최종 제출본 전체의 운영 검증을 의미하지 않습니다.

## 직접 사용한 결과

사용자가 배포 사이트 접속, Slack 계정 연결, 테스트 DM과 실제 예약 메시지 수신을 확인했습니다. 언어·테마는 휴대전화 2대·태블릿 1대·개발 PC에서 동작을 확인했습니다. 다른 PC 1대에서 선택과 쿠키가 바뀌지 않는 현상이 있어 포커스 처리를 보완했으며 해당 PC의 재확인은 남아 있습니다.

별도 실서버 QA에서 임시 계정의 가입·프로젝트·일정·할 일·계정 변경·삭제 흐름도 확인한 기록이 있습니다. 이 QA에서는 Slack 승인·발송을 실행하지 않았습니다. 자세한 조건은 [실서버 QA 기록](qa-live-2026-10-22.md)을 참고합니다.

## 자동 검사 결과

| 방법                                      | 범위                                                                 | 기록                                                           |
| ----------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------- |
| `npm run test:audit`                      | 입력 검증, 탈퇴 보호, 날짜 경계, 조건부 보관                         | 통과                                                           |
| `npm run test:workspace`                  | 캘린더·홈 분류·번역                                                  | 통과                                                           |
| `npm run test:reminders`                  | 예약·취소·상태 대조·OAuth·토큰 경로                                  | 통과                                                           |
| `npm run test:performance`                | 비밀번호·세션·계정·날짜·표시 효과                                    | 통과                                                           |
| `node scripts/check-auth-rate-limit.mjs`  | 제한 해제 시각·Retry-After 해석                                      | 통과                                                           |
| Playwright·Chrome 모의 API 검사           | 등록·재시도·보관·복원·캘린더 이동·도움말·초점·반응형 배치            | 통과                                                           |
| `node scripts/check-appearance-focus.cjs` | 모션 감소 켬·끔, null 포커스 이벤트 주입, 선택·쿠키·재방문·메뉴 닫기 | 통과                                                           |
| `npm run lint`                            | TypeScript 타입 검사                                                 | API 명세 수정 후 통과                                          |
| `npm run build`                           | Nuxt/Nitro 프로덕션 빌드                                             | 이전 코드 점검에서 통과. 이후 변경을 포함한 최종 빌드는 미실행 |

자동 검사 코드의 작성과 실행에도 AI 도구를 활용했습니다. 모의 API 검사의 성공은 실제 DB 변경·Slack 전송 성공의 증거로 사용하지 않았습니다. 이전 코드 점검의 상세 조건은 [추가 점검 보고서](code-audit-followup-2026-10-22.md), 이후 명세·설명 수정과 재실행 범위는 [문서 대조 기록](documentation-consistency-2026-10-22.md)을 참고합니다.

## 남은 확인

- 최종 코드의 프로덕션 빌드와 배포 반영 확인. 특히 회원가입 시간당 20회·재시도 시각 표시·언어 및 테마 포커스 수정은 로컬 코드 기준으로 기록했습니다.
- 문제 PC에서 실제 마우스 선택·쿠키 저장·새로고침 후 유지 확인. 의심 이벤트 주입 검사는 실제 원인을 확정하지 않습니다.
- 대량 데이터의 응답 시간·크기 측정, 목록 페이지네이션.
- 운영 DB에서 항목 변경·알림·연결 변경·탈퇴가 겹치는 요청의 경합 검증.
- Slack 장애·권한 철회·응답 지연·탈퇴 취소 큐와 정기 재시도의 운영 검증.
- 새 빈 DB에서 전체 구축 절차의 실검증.

실행 준비와 검사 명령은 [로컬 개발 안내](local-development.md), 현재 제공하지 않는 기능은 [README](../README.md)의 남은 항목을 참고합니다.
