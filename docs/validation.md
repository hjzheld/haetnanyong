# 검증 기록

기록 기준일: **2026-10-22 (KST)**. 사용자 직접 확인과 AI 도구로 수행한 자동 검사를 구분했습니다. 이번 코드 점검의 변경 내용은 [최종 점검 보고서](code-audit-final-2026-10-22.md)에 정리했습니다.

## 직접 사용한 결과

사용자가 배포 사이트 접속, Slack 계정 연결, 테스트 DM과 실제 예약 메시지 수신을 확인했습니다. 언어·테마는 휴대전화 2대·태블릿 1대·개발 PC에서 동작을 확인했고, 포커스 처리 보완 후 문제 PC에서도 실제 마우스 선택이 정상 반영되는 것을 확인했습니다. 수정 전 이벤트 순서는 직접 기록하지 않았으므로 원인 추정과 해결 결과를 구분합니다.

별도 실서버 QA에서 임시 계정의 가입·프로젝트·일정·할 일·계정 변경·삭제 흐름을 확인한 기록도 있습니다. 해당 QA에서는 Slack 승인·발송을 실행하지 않았습니다. 조건과 결과는 [실서버 QA 기록](qa-live-2026-10-22.md)을 참고합니다.

검사 코드를 작성하고 실행하는 데 AI 도구를 활용했습니다. 자동 검사의 성공을 실제 DB 변경·Slack 발송 성공의 증거로 해석하지 않았습니다. 개발 서버 일부 검사에서 초기 스크립트 로딩 타임아웃이 있었으므로 개발 서버 결과만으로 통과 처리하지 않고 프로덕션 빌드에서 다시 확인했습니다.

## 남은 확인

- 운영 배포 반영 확인. 이번 빌드 통과가 배포 완료를 뜻하지는 않습니다.
- 대량 데이터의 응답 시간·크기 측정과 목록 페이지네이션.
- 운영 DB에서 항목 변경·알림·연결 변경·탈퇴가 겹치는 요청의 경합 검증.
- Slack 장애·권한 철회·응답 지연·탈퇴 취소 큐와 정기 재시도의 운영 검증.
- 새 빈 DB에서 전체 구축 절차의 실검증.

이번 점검에서는 실제 DB 접속·마이그레이션·사용자 변경·Slack 발송·취소·배포를 실행하지 않았습니다. 이전 캘린더 점검의 운영 DB 읽기 연결도 실패해 실데이터 확인은 하지 못했습니다. 실행 준비는 [로컬 개발 안내](local-development.md), 과거 결과는 [추가 점검 보고서](code-audit-followup-2026-10-22.md)를 참고합니다.
