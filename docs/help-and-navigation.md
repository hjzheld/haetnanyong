# 화면 도움말과 뒤로가기

- 모달이 열리면 공통 `modal-scroll.client.ts`에서 배경 스크롤을 잠급니다. 여러 모달이 겹치면 마지막 모달이 닫힐 때까지 유지하고, 모두 닫힌 뒤 기존 스크롤 위치와 스타일을 복원합니다. 모달 자체의 내용 스크롤은 유지합니다.

- 다른 페이지로 이동하면 공통 라우터 설정에서 맨 위로 부드럽게 스크롤합니다. 뒤로가기에도 적용하며, 같은 페이지의 탭·필터 변경은 위치를 유지합니다. 해시 링크는 지정 영역으로 이동하고 모션 감소 설정에서는 애니메이션 없이 이동합니다. 설정은 `app/router.options.ts`에 있습니다.

- 일정·할 일 등록/상세/수정의 `뒤로가기`는 내부 방문 기록으로 돌아갑니다. 직접 접속해 이전 화면이 없으면 프로젝트 상세 또는 개별 플랜으로 이동합니다.
- 등록 후 상세 화면은 등록 화면의 방문 기록을 대체합니다. 따라서 상세에서 뒤로가기를 누르면 캘린더 등 등록을 시작했던 화면으로 돌아갑니다.
- 상세에서 수정한 뒤 저장하면 원래 상세 화면으로 돌아갑니다. 저장하지 않은 입력은 이탈 확인을 표시하며, 취소 버튼에서 확인한 경우 중복으로 묻지 않습니다.
- 페이지 제목 옆에 도움말을 표시합니다. 제목 컴포넌트가 없는 소개·정책·Slack 연결 결과 화면은 본문 상단에 표시합니다. 로그인·회원가입 화면에는 도움말을 표시하지 않습니다. 오류 화면에도 복구 도움말이 있습니다.
- 플랜은 기존 전용 도움말을 유지하고, 나머지 화면은 `CommonPageHelp`에서 경로에 맞는 한국어/영어 설명을 제공합니다.
- 도움말은 모달로 열리며 Escape/닫기 버튼으로 닫고 도움말 버튼으로 초점을 복원합니다.
- 예약 알림 관리 칸은 `table-cell`을 유지하며 내부 버튼 묶음만 flex로 배치합니다. 버튼 문구는 줄바꿈하지 않고 좁은 화면에서는 표 안에서 가로 스크롤합니다.

## 검증

개발 서버 실행 후 `node scripts/check-help-navigation.cjs`로 이전 화면 복귀, 저장 후 복귀, 화면별 도움말과 초점 복원, 320/390/768/1440px 알림 표를 검사합니다. API는 모두 모의 응답이므로 Neon 데이터나 실제 Slack 메시지는 변경하지 않습니다.
