# Backend services

이 폴더의 실제 서비스 모듈은 다음 두 개입니다.

- `slack.ts`: Slack API 호출·오류 분류, 채널별 설치 토큰 조회, 예약·취소·예약 목록 조회
- `reminders.ts`: 메시지 해시, 소유권 확인, 예약 목록 대조, 버전 조건부 갱신, 취소, 일정·Slack 연결 변경 전 활성 예약 검사

`hasActiveReminders`는 미래 예약이나 불확실한 상태가 있으면 차단합니다. 과거 `SCHEDULED`만 남으면 채널별 예약 목록을 재사용해 대조하고 DB 상태를 다시 검사합니다. 조회 실패나 Slack에 남아 있는 예약은 그대로 보호합니다. 15초 예산은 외부 호출용이며 DB를 포함한 전체 응답 시간 보장은 아닙니다.

로그인·프로젝트·할 일·일정·캘린더·홈 API는 `server/api/`, 공통 인증·입력 검증·DB 접근은 `server/utils/`에 있습니다. 기간별 캘린더 API는 본인 일정만 반환하고 할 일은 포함하지 않습니다. 보관된 프로젝트 일정도 조회하며 화면의 프로젝트 필터는 프론트에서 적용합니다.

현재 대조는 대기 중인 예약 목록을 검사하는 기능입니다. 실제 게시 여부·읽음·기기 푸시 수신을 확인하지 않습니다. [Slack 운영 안내](../../docs/slack-reminders.md)를 참고합니다.
